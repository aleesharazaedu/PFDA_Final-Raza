# (WIP) Light-horror RPG

## Repository
<https://github.com/aleesharazaedu/PFDA_Final-Raza/>

## Description
1-2 sentence description of what it will do and how it is relevant to media and digital arts.
This program will follow a simple narrative through the perspective of a controllable main character. The player can explore different locations and gain more details on their whereabouts accordingly.

## Features
- Inventory
	- Will require some use of lists/indexing, while having a visual asset that corresponds. (e.g., weapons, books, etc.)
- Puzzle
	- Using logic, random, or math combined with Pygame elements, the game should introduce some kind of challenge to the player in a puzzle form.
- Visible map
	- A corresponding key, through a simple Pygame command, should bring up a small visual of the tilemap environment that is easy to navigate using smaller images of assets such as floors, or grass. 

## Challenges
- Creating an inventory and map system as well as its visible UI for a player to interact with will have to be learned.
- Learning how to correspond certain keys to certain movements and actions.
- Progressing the story based on changes in a character's status or the execution of main events.

## Outcomes
Ideal Outcome:
- The ideal outcome is a visually appealing short top-down style RPG that introduces simple yet interactive game mechanics, as well as a mysterious and brief narrative that peaks a player's curiousity.

Minimal Viable Outcome:
-  At its core, the game will successfully introduce a short narrative with a beginning, middle, and end. It should also allow the player to move around and discover items or details as it progresses. 

## Milestones

- Week 1
  1. Create a very loose foundation for the game and its progression, as well as a tilemap.
  2. Learn the tools needed to implement certain mechanics such as an inventory.

- Week 2
  1. Begin to create assets such as sprites, music, and background elements to add visual appeal.
  2. Work on perfecting the mechanics and finalizing the execution of a basic story in the program.

- Week N (Final)
  1. Final touches and playtesting to ensure all elements are working properly.
  2. Adding less important elements, whether that is visually or with lower-priority mechanics, such as a small side quest.
